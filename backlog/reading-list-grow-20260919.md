
# 登録した本を一覧から削除でき、直後なら取り消せる

いまの一覧は「追加」と「読了／未読に戻す」しかできず、一度登録した本を消す手段がない。タイトルを打ち間違えた行も、読むのをやめた本も残り続け、使うほど「これから読む本」が埋もれていく。各行に「削除」ボタンを置き、押すとその本を一覧と localStorage から取り除く。「読了」の隣に並ぶ押し間違いに備え、削除の直後は「元に戻す」を表示し、押せば同じ位置・同じ読了状態で復元する。取り消せるのは直前の1件だけで、ページ内のメモリにだけ持ち、リロードすれば消える。保存形式（`id` / `title` / `done` の配列）は変えない。一覧が「いま読みたい本」だけに保たれ、打ち間違いも消して入れ直せるようになる。

## 意図

読みたい本をメモしている人が、打ち間違えた行や読む気のなくなった本を一覧から外し、リストを今の関心に合わせておくために使う。
押し間違えても直後なら戻せるので、確認ダイアログなしで気軽に整理できる。

## 受け入れ条件の種

- 本を2冊追加して1冊目の「削除」を押すと、`.book-item` が1件になり残った行のタイトルは2冊目のものになる。リロードしても削除した本は表示されない。最後の1冊を削除すると `#empty-message` が表示される
- 読了にした本を削除した直後は「元に戻す」が表示され、押すとその本が元の位置に読了状態（打ち消し線、ボタン文言「未読に戻す」）のまま表示され、リロード後も残っている。削除する前とページをリロードした後は「元に戻す」を描画しない
- `.book-item` / `.book-title` / `.toggle-done` / `#empty-message` のセレクタとその文言、localStorage のキー `reading-list-books` と保存形式は変えず、既存のテストがすべて通る。削除機能のない版で保存された一覧もそのまま表示される
